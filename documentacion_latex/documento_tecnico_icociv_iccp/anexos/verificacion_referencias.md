## Referencias descartadas por ahora

- Fuentes que solo aparecían como catálogos, fichas comerciales, páginas de compra o resúmenes sin texto completo no se incluyeron.
- Referencias estadísticas avanzadas no usadas explícitamente en este documento técnico corto, como NIST o skforecast, se dejaron fuera para evitar referencias no citadas.
- Documentos de caso local no citados directamente en el texto, como Anexos C, F y G, se conservaron como fuentes disponibles para capítulos posteriores, pero no se agregaron a `referencias.bib` para mantener correspondencia estricta entre citas y referencias.
